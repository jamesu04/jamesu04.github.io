記帳統計 隱私權政策

最後更新：2026-11-20

「記帳統計」是只供作者本人使用的 Android app。

存取的資料

經使用者以 Google 帳號授權後，app 透過 Google Sheets API 讀取使用者自己指定的一份試算表中的記帳資料，並且只會修改同一份試算表中的「預算」分頁。

資料的使用與保存

  • 資料只在使用者自己的手機上處理與顯示。
  • app 沒有自己的伺服器，不會把任何資料傳送給第三方。
  • 不收集、不分享、不出售任何個人資料，不含廣告或分析工具。

本 app 對 Google API 所取得資料的使用，遵守 Google API Services User Data Policy，包含其中的 Limited Use 規定。

撤銷授權

可隨時在 Google 帳戶的第三方存取權頁面 移除本 app 的存取權。
